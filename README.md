# Expense Tracker

**Expense Tracker** is a Python application for personal finance management, including expense tracking, visualization, goal setting, budgeting, insights, and trend prediction. It works via the console and uses CSV, JSON, Excel, and matplotlib for storage and plotting.

---

## Features

- Add, edit, delete, and search expenses
- Visual summary and plots (category, monthly, comparison)
- Save/load expenses to CSV, JSON, Excel
- Set and check monthly budgets per category
- Add, update, and display financial goals (with progress)
- Analyze spending trends and category ratios
- Predict next month’s spending using linear regression
- Export-ready placeholders for Google Sheets integration

---

## Requirements
- Python 3.x
- Packages: `matplotlib`, `pandas`, `numpy`
